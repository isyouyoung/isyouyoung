## Main Project

### K-Stock Compass

국내 주식 투자자를 위한 주식 정보 및 목표가 알림 서비스

#### Key Features

* 회원가입 / 로그인
* JWT Access Token / Refresh Token 인증
* Redis 기반 Refresh Token 관리
* 이메일 인증번호 TTL 관리
* 한국투자증권 Open API 연동
* 관심종목 등록 및 관리
* 목표가 알림 서비스
* 실시간 주식 검색

#### Tech

Spring Boot · Spring Security · JPA · MariaDB · Redis · Docker · AWS EC2

#### Problem Solving

* JWT 인증 헤더 자동화
* Access Token / Refresh Token 재발급 구조 설계
* Redis 기반 인증번호 자동 만료 처리
* KIS API 토큰 캐싱으로 불필요한 API 호출 최소화
